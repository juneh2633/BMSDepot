# 0.1.0-alpha.1

첫 알파 버전입니다. Depot에서 BMS 곡을 검색·다운로드하고 난이도표별로 정리합니다. 일반 OpenLR2를 별도로 실행한 뒤 선곡 화면에서 F8로 목록을 갱신해 사용합니다.

- 곡명·아티스트 검색과 난이도표 필터
- 여러 채보 순차 다운로드와 취소
- 채보 해시·필수 음원 확인
- 난이도표·레벨별 폴더와 공용 음원 연결
- 기존 설치곡 분류와 설치 상태 갱신
- 저장 용량·보관 기간 설정

`*-setup.exe`는 설치형, `*-win-x64.zip`은 포터블 버전입니다. Windows x64용이며 .NET 런타임을 포함합니다. OpenLR2와 곡 원본은 포함하지 않습니다.

현재 빌드를 확인한 단계입니다. 일반 OpenLR2에서의 F8 반영·분류 폴더 재생과 다운로드 취소·복구는 아직 실제 동작을 확인하지 못했습니다. 모든 곡의 다운로드 가능성을 보장하지 않습니다.

분류 폴더에는 같은 NTFS 드라이브가 필요합니다. 분할·중첩 압축과 BMSON은 지원하지 않습니다. 사용법과 이전 버전의 경로 변경은 README를 참고하세요.
