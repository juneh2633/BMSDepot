# 0.1.0-alpha.1

첫 알파 버전입니다. Depot에서 BMS 곡을 검색·다운로드하고 난이도표별로 정리합니다. LR2나 OpenLR2를 별도로 실행하고 곡 목록을 갱신해 사용합니다. OpenLR2는 선곡 화면에서 F8을 누릅니다.

## 설치와 시작

1. 아래 Assets에서 `BMSDepot-0.1.0-alpha.1-win-x64-setup.exe`를 받습니다.
2. 실행 후 **설치하고 시작**을 누릅니다. .NET SDK·런타임 설치는 필요하지 않습니다.
3. Depot의 **경로 복사**로 곡 폴더를 게임에 등록합니다.
4. Depot에서 곡을 다운로드하고 게임에서 목록을 갱신합니다.

카탈로그가 포함되어 있으므로 따로 받을 필요는 없습니다. 설치 없이 쓰려면 포터블 ZIP을 폴더에 풀고 `BMSDepotNext.exe`를 실행하세요.

## 기능

- 곡명·아티스트 검색과 난이도표 필터
- 여러 채보 순차 다운로드와 취소
- 채보 해시·필수 음원 확인
- 난이도표·레벨별 폴더와 공용 음원 연결
- 기존 설치곡 분류와 설치 상태 갱신
- 저장 용량·보관 기간 설정

`*-setup.exe`는 설치형, `*-win-x64.zip`은 포터블 버전입니다. Windows x64용이며 .NET 런타임을 포함합니다. 구동기와 곡 원본은 포함하지 않습니다.

현재 빌드를 확인한 단계입니다. LR2·OpenLR2의 분류 폴더 갱신·재생과 다운로드 취소·복구는 아직 실제 동작을 확인하지 못했습니다. 모든 곡의 다운로드 가능성을 보장하지 않습니다.

분류 폴더에는 같은 NTFS 드라이브가 필요합니다. 분할·중첩 압축과 BMSON은 지원하지 않습니다. 사용법과 이전 버전의 경로 변경은 README를 참고하세요.
