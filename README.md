# BMS Depot

BMS 곡을 찾아 받고, 난이도표와 레벨별로 정리하는 Windows 프로그램입니다. LR2나 OpenLR2는 평소처럼 따로 실행하면 됩니다.

Depot에서 다운로드한 뒤 사용하는 구동기에서 곡 목록을 다시 읽으면 됩니다. OpenLR2에서는 선곡 화면의 **F8**을 사용합니다. 게임 실행 파일을 교체하거나 플러그인을 설치할 필요는 없습니다.

> 현재 알파 버전입니다. 빌드는 확인했지만 LR2·OpenLR2에서의 폴더 갱신·재생과 다운로드 취소·복구는 아직 실제 동작을 확인하지 못했습니다.

## 설치

[0.1.0-alpha.1 릴리스](https://github.com/juneh2633/BMSDepot/releases/tag/v0.1.0-alpha.1)에서 받습니다.

- [Windows 설치 파일](https://github.com/juneh2633/BMSDepot/releases/download/v0.1.0-alpha.1/BMSDepot-0.1.0-alpha.1-win-x64-setup.exe)
- [포터블 ZIP](https://github.com/juneh2633/BMSDepot/releases/download/v0.1.0-alpha.1/BMSDepot-0.1.0-alpha.1-win-x64.zip)
- [SHA256 목록](https://github.com/juneh2633/BMSDepot/releases/download/v0.1.0-alpha.1/SHA256SUMS.txt)

- **`*-setup.exe`**: 실행 후 **설치하고 시작**
- **`*-win-x64.zip`**: 압축을 풀고 `BMSDepotNext.exe` 실행

Windows x64용입니다. **사용자는 .NET SDK나 런타임을 따로 설치할 필요가 없습니다.** `catalog.json`도 포함되어 있습니다. 포터블 ZIP은 실행 파일만 꺼내지 말고 나머지 파일을 같은 폴더에 두세요. LR2 등 BMS 구동기는 별도로 준비합니다. 곡은 Depot에서 다운로드합니다.

## 처음 사용할 때

1. Depot 상단의 **경로 복사**를 누릅니다.
2. 사용하는 구동기의 곡 폴더 설정에 복사한 경로를 추가합니다.
3. Depot에서 난이도표를 고르고 곡명이나 아티스트를 검색합니다.
4. 곡을 선택하고 **선택한 곡 다운로드**를 누릅니다.
5. 완료되면 게임의 곡 목록을 갱신합니다. OpenLR2는 선곡 화면에서 **F8**을 누릅니다.

등록할 경로는 다음과 같습니다.

```text
%LOCALAPPDATA%\BMSDepotNext\library\난이도표
```

목록이 바로 바뀌지 않으면 상위 폴더로 나갔다가 다시 들어오세요. 플레이 중에 다운로드했다면 선곡 화면으로 돌아온 뒤 갱신하면 됩니다. 다운로드가 끝난 곡은 Depot를 꺼도 사용할 수 있습니다.

게임 안에서 미설치 곡을 눌러 받는 방식은 아닙니다. 검색과 다운로드는 Depot에서 합니다.

### 여러 곡 받기

Ctrl이나 Shift를 누르고 여러 채보를 선택하면 순서대로 받습니다. 한 곡이 실패해도 나머지는 계속 처리합니다. **다운로드 취소**를 누르면 남은 작업을 멈추고, 완료된 곡은 남깁니다. 실패한 이유는 하단 **오류 내용**에서 확인할 수 있습니다.

다운로드 중 창을 닫으면 작업을 유지하며 최소화됩니다.

### 난이도별 폴더

```text
난이도표
├─ Satellite
│  ├─ sl0
│  └─ sl1
└─ Stella
   ├─ st0
   └─ st1
```

특정 난이도표에서 받은 채보는 그 표와 레벨에 들어갑니다. **전체 카탈로그**에서 받으면 소속된 모든 표에 연결합니다. 곡 폴더에는 선택한 채보 하나만 표시합니다.

음원과 이미지는 공용 캐시에 한 번 저장하고 하드 링크로 공유합니다. 같은 NTFS 드라이브가 필요합니다. 분류 폴더에서 파일을 편집하면 원본도 바뀌므로 직접 수정하지 마세요. 탐색기에서 폴더 크기를 합산하면 공유 파일이 중복 집계될 수 있습니다.

기존에 받은 곡은 게임을 종료한 뒤 **기존 설치곡을 난이도 폴더로 정리**를 누르면 됩니다. 파일을 직접 정리한 후에는 **설치 상태 갱신**으로 표시를 새로 읽을 수 있습니다.

### 이전 버전에서 넘어오는 경우

구동기에 등록했던 `list`, `Depot Online`, `library\songs` 경로를 등록에서 제외하고 위의 `library\난이도표` 경로만 사용하세요. **`library\songs` 폴더 자체를 지우면 안 됩니다.** 실제 곡 파일을 보관하는 곳입니다.

## 구동기 호환성

일반 BMS 파일을 폴더로 제공하므로 OpenLR2 전용 연동은 사용하지 않습니다. 다만 파일을 읽을 수 있는 구조와 실제 재생 확인은 별개입니다.

| 구동기 | 현재 상태 |
|---|---|
| LR2 | 사용 대상. 최신 분류 폴더의 실제 재생은 미확인 |
| OpenLR2 | 사용 대상. F8 재검색을 이용하며 최신 분류 폴더의 실제 재생은 미확인 |
| 그 외 BMS 구동기 | 파일 형식·폴더 탐색·갱신 방식에 따라 달라지며 호환성 미확인 |

다른 구동기는 실행 상태 감지도 지원하지 않습니다. 사용 중인 구동기를 감지하지 못하면 자동 정리로 파일이 삭제될 수 있으므로, 호환성을 확인하기 전에는 플레이 중 Depot를 종료하세요. 이미 받은 곡은 Depot 없이 사용할 수 있습니다.

## 저장 공간

**저장 공간 · 보관 설정**에서 용량은 1~200 GiB, 기간은 1~3650일로 설정할 수 있습니다. 최근 다운로드하거나 설치를 확인한 시점을 기준으로 오래된 곡부터 정리합니다. 게임에서 마지막으로 플레이한 시점은 알 수 없습니다.

LR2·OpenLR2 실행을 감지한 동안에는 기존 곡을 자동 삭제하거나 교체하지 않습니다. 공간이 부족하면 게임을 종료하고 보관 설정을 저장한 뒤 다시 받으세요. 실행 감지는 `OpenLR2...`, `LR2body`라는 프로세스 이름을 사용하므로 구동기 이름을 바꾸지 않는 편이 좋습니다.

설정과 캐시는 `%LOCALAPPDATA%\BMSDepotNext`에 저장합니다. 게임 설정·점수·리플레이는 Depot에서 변경하지 않습니다.

## 잘 안 될 때

| 증상 | 확인할 것 |
|---|---|
| 다운로드한 곡이 안 보임 | 새 경로 등록, 구동기의 곡 목록 재검색, 폴더 재진입. OpenLR2는 선곡 화면에서 F8 |
| 같은 곡이 중복 표시됨 | 이전 경로와 공용 캐시 경로를 곡 폴더 등록에서 제외 |
| 기존 곡이 분류되지 않음 | 게임 종료 후 **기존 설치곡을 난이도 폴더로 정리** |
| 폴더 연결 실패 | NTFS인지, 접근 권한과 여유 공간이 있는지 확인 |
| 다운로드 실패 | 하단 오류 내용에서 출처·차분·음원 오류 확인 |
| 설치됨 표시가 맞지 않음 | **설치 상태 갱신**, **설치 확인·폴더 연결** |

오류 기록은 `%LOCALAPPDATA%\BMSDepotNext\errors.log`에 남습니다. 제보할 때는 앱 버전, 곡명, 난이도표와 오류 메시지를 함께 적어 주세요.

현재 카탈로그에는 16,263개 채보가 있습니다. 출처가 사라졌거나 원곡이 없는 차분은 받지 못할 수 있습니다. 단일 ZIP/RAR/7z와 Horie 차분을 지원합니다. 분할·중첩 압축, BMSON, 카탈로그 자동 갱신은 지원하지 않습니다.

## 빌드

Windows와 .NET SDK 9.0.318이 필요합니다.

```powershell
./next/Build.ps1 -Version 0.1.0-alpha.1
```

설치 파일, 포터블 ZIP, SHA256 목록이 `artifacts/release/0.1.0-alpha.1`에 생성됩니다. GitHub Actions도 같은 스크립트를 사용합니다. `v`로 시작하는 버전 태그를 올리면 프리릴리스 초안을 만듭니다. [배포 절차](docs/PUBLISH.md)
