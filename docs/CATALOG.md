# 카탈로그 출처와 갱신

`next/catalog.json`은 기존 BMS Depot 수집 작업에서 보관한 메타데이터를 단순화한 스냅샷입니다. 2026-10-18 공개 준비 시점에 MD5가 있는 16,263개 채보를 포함합니다. 날짜는 이번 패키징 시점이며 각 원본 사이트의 최종 갱신일을 의미하지 않습니다.

## 주요 출처

- [Horie BMS Library](https://horieyuuka.github.io/) — 원곡·차분 검색 및 다운로드 출처 정보
- [Stella/Satellite 난이도표](https://stellabms.xyz/) 및 각 난이도표 운영자 — 표 이름과 레벨 소속
- 원곡 제작자·배포 페이지 — 카탈로그 각 항목의 Sources에 기록된 배포 주소

형식은 곡/채보 식별자, 제목·아티스트, MD5/SHA256, 난이도표 소속, 다운로드 출처로 구성됩니다. 출처와 난이도표 정보는 변경되거나 중단될 수 있습니다. 이 앱은 Horie나 OpenLR2의 공식 제품이 아닙니다.

## 권리 범위

앱 소스의 MIT 라이선스는 카탈로그의 원본 메타데이터, 원곡, 차분, 이미지·영상의 권리를 이전하지 않습니다. 원저작자와 데이터 출처의 권리를 존중하고 원본 배포 조건을 확인하세요. 이 저장소에는 음악·원곡 압축 파일을 포함하지 않습니다.

## 갱신

이번 공개용 저장소에는 검토된 카탈로그 스냅샷만 포함합니다. 자동 크롤러나 주기적 갱신 기능은 포함하지 않습니다. 관리자가 카탈로그를 교체하면 식별자·해시·난이도표·출처가 유지되는지 확인하고 빌드합니다. 카탈로그 변경은 앱 버전 또는 릴리스 노트에서 사용자에게 알려야 합니다.
